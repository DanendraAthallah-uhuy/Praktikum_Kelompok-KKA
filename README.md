# 🎮🖥️ Praktikum_Kelompok-KKA  
## Implementasi Object-Oriented Programming (OOP) dengan Python

Project ini merupakan tugas praktikum kelompok yang mengimplementasikan konsep **Object Oriented Programming (OOP)** menggunakan bahasa Python.

Project terdiri dari dua bagian utama:
1. 🎮 Simulasi Game RPG  
2. 🖥️ Sistem Penjualan Barang Elektronik  

---

# 🎮 Simulasi Game RPG  
## File: `game_rpg.py`

Seluruh konsep OOP pada bagian game digabung dalam satu file:

```
game_rpg.py
```

### 📌 Konsep yang Didemonstrasikan
- Class & Object  
- Inheritance  
- Encapsulation  
- Abstraction  
- Polymorphism  

### ▶️ Cara Menjalankan Game

1. Pastikan Python sudah terinstall.
2. Buka Terminal / Command Prompt.
3. Masuk ke folder tempat file berada.
4. Jalankan perintah:

```bash
python game_rpg.py
```

### ✅ Saat Program Dijalankan

Program akan secara otomatis menampilkan:
- Demonstrasi Class & Object  
- Demonstrasi Inheritance  
- Demonstrasi Encapsulation  
- Demonstrasi Abstraction  
- Demonstrasi Polymorphism  

Output berupa:
- Informasi karakter
- Proses serangan
- Pengurangan HP
- Skill khusus Mage
- Perbedaan perilaku antar class

Program berjalan dari awal hingga akhir dalam satu kali eksekusi.

# 🖥️ Sistem Penjualan Barang Elektronik  
## File: `kelompok.py`

Program ini merupakan simulasi sistem penjualan barang elektronik berbasis OOP.

```
kelompok.py
```

---

## 📌 Fitur
- Abstract Class untuk struktur barang  
- Encapsulation untuk keamanan data  
- Inheritance antar class  
- Polymorphism pada perhitungan pajak  
- Validasi stok barang  
- Cetak struk transaksi  

---

## 🧠 Konsep OOP yang Digunakan
- Abstraction  
- Encapsulation  
- Inheritance  
- Polymorphism  

---

## 📦 Jenis Barang
- Laptop (Pajak 10%)  
- Smartphone (Pajak 5%)  

---

## ▶️ Cara Menjalankan Sistem Penjualan

1. Pastikan Python sudah terinstall.
2. Masuk ke folder project.
3. Jalankan perintah:

```bash
python kelompok.py
```

---

# 📊 Ringkasan 4 Pilar OOP

| Konsep        | Implementasi |
|--------------|--------------|
| Abstraction  | Abstract class pada Game & Penjualan |
| Encapsulation| Private attribute + Getter/Setter |
| Inheritance  | Mage, Hero, Laptop, Smartphone |
| Polymorphism | Override method serang() & hitung_pajak() |
